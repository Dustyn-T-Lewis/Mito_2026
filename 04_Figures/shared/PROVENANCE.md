# Shared enrichment artifacts

The figure stage's enrichment panels (F01, F02) share one gene-set collection and
one fGSEA cache. Both are regenerated by tracked builders in `a_script/` and written
to `c_data/` (gitignored, like every other `c_data/`). Regenerate them after any
change to the DE results or the gene-set sources.

## Builders (`a_script/`)

| Script | Output (`c_data/`) | Sources |
|---|---|---|
| `01_fetch_rat_gene_sets.R` | `rat_gene_sets.rds` | `msigdbr` (rat) + `org.Rn.eg.db`/`GO.db` + `mitocarta3_rat.rds` |
| `02_build_fgsea_cache.R` | `fgsea_tstat_all_h9c2.csv` | `03_DEP/a_non_imputed/c_data/combined_results_pi.csv` + `rat_gene_sets.rds` |
| `00_gene_set_helpers.R` | — | `build_goslim_gene_sets()`, `run_fgsea_cache()` |

Run order: `01` then `02` (the cache reads the collection).

## Gene-set sources

- **Hallmark, KEGG (legacy), Reactome** — `msigdbr(species = "Rattus norvegicus")`.
  KEGG uses `CP:KEGG_LEGACY` (rat orthologs; `CP:KEGG_MEDICUS` is human-only). The
  installed `msigdbr` version is recorded in the rds `provenance` attribute.
- **GO Slim** — 62 GO Slim Generic BP terms expanded over `GO.db::GOBPOFFSPRING` and
  mapped to symbols via `org.Rn.eg.db`, size-filtered to 10–500.
- **MitoCarta** — `mitocarta3_rat.rds` (tracked). Derived from Broad MitoCarta3.0
  (Rattus norvegicus). The upstream `Rat.MitoCarta3.0.xls` is **not** committed; this
  rds is the only copy, so it is tracked rather than treated as a regenerable cache.
  Replacing it requires the Broad source.

Each database is collapsed within itself by Jaccard ≥ 0.5 (larger set kept).
Cross-database / containment redundancy is handled at runtime by the dedup engine
(`functions/03_pathway_enrichment_dedup_ora.R`), not here.

## Consumers

`functions/03_pathway_enrichment_dedup_ora.R` (`build_harmonized_collection`),
`F01_Proteome_Overview/a_script/panels/pathway.R`, and
`F02_Enrich_Volcanoes/a_script/01_enrich_volcanoes.R` read from `c_data/`.

## Reproducibility

With `msigdbr 26.1.0`, the regenerated `rat_gene_sets.rds` and
`fgsea_tstat_all_h9c2.csv` are byte-for-byte identical (content) to the original
committed cache, verified across all five gene-set blocks and all fGSEA statistics.
A different `msigdbr`/`org.Rn.eg.db`/`GO.db` release may shift which sets exist;
diff against the prior cache before adopting a rebuild.
